# CONFIG

All the different options for the glorious mcsb.config file

## Nessesary options

### mode | String
This option specifies what mode to run in
    - 1. Standalone
    - 2. Manager
    - 3. Worker
    - 4. Hybrid

### nodeName | String
This specfies the name of the node, will be used whenever the node is refered to
